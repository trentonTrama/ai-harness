# Revision Checklist

Run this against any draft before delivering it — one you just wrote or one you are revising. Work top-down — structural problems change the bullets, so fixing language first wastes effort.

## Pass 1 — Structure

- [ ] Does the first sentence name the **shape** (the phases ahead) or the **threshold** (what gates what)? If it argues, ranks, or sets stakes, rewrite it.
- [ ] Is there anything before that first sentence? Delete it.
- [ ] Are there phase headers? Justify each one: does the next phase actually consume the output of the previous? If not, flatten to a single bullet list.
- [ ] Does every phase have a preamble? If so, delete the ones whose bullets are self-evident. Symmetry is not a reason to keep one.
- [ ] Any transition sentences between sections? Delete them.
- [ ] Any closing summary, recap, or encouragement? Delete it. The document ends on its last bullet or its table.
- [ ] Is there a general/specific split (region, tool, org)? General method first, then the carve-out with backticked URL patterns and `[BRACKETED-TOKENS]`.

## Pass 2 — Bullets

- [ ] Does any bullet start with a bolded label? Rewrite so it starts with the verb or the subject.
- [ ] Does every bullet naming a tool also name what the tool is for?
- [ ] For each two-sentence bullet: does sentence two draw a **non-obvious inference**? If it elaborates, restates, or softens, cut it.
- [ ] For each bullet describing a taste, reading, symptom, or measurement: are **both** failure directions named? This is the most commonly missed rule.
- [ ] Are constraints and safety notes plain bullets sitting where they become relevant? Remove any callout blocks, icons, or `WARNING` styling.
- [ ] Is bold used anywhere except headers and table keys? Remove it.

## Pass 3 — Language

- [ ] Are the nouns hyper-specific to the domain, and the verbs conversational? Flag any lab-register phrasing (`hold X constant`, `utilize`, `ensure that`) and rewrite plainly.
- [ ] Does every specific singular noun keep its article? Scan for `adjust output`, `pull error rate`, `check status` — add `the`. Bare plurals and mass nouns stay as they are.
- [ ] Are inferences hedged on a calibrated scale (*strongly indicates / usually indicates / often yields*)? Fix both absolutes and mush.
- [ ] Is each acronym expanded once parenthetically, then bare? Are non-acronym domain terms left undefined?
- [ ] Are all quantities specific figures with units? Replace "a few," "several," "some time."

## Pass 4 — Tables

- [ ] Is there a schema or parameter set that belongs in a table?
- [ ] Is the table last, with no conversational padding above or below it?
- [ ] Property names bolded, descriptions as noun phrases with no terminal periods?
- [ ] Is there a table that exists only because tables look thorough? Delete it — a document with no schema gets no table.

## Pass 5 — Banned Moves

Scan for and remove: marketing language, dramatic hooks, forced metaphors, "It's worth noting," "Remember that," emoji, decorative horizontal rules between every section, equal-length phases padded to match, a fixed bullet count per section.

## Reporting

When revising someone else's draft, list what changed by rule number rather than silently rewriting. The user needs to see which rule caught which line.
